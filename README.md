# 电商竞品自动采集 + 个人工作台

一套跑在 **GitHub 云端** 的自动化系统：每天 00:05（北京时间）自动采集淘宝/闲鱼同行数据，
抓数据、下图片、读卖点，生成数据文件和 PPT，自动归档到云端并按「日期 + 平台 + 类型」分类，
同时生成一份「个人工作台」网页，手机电脑都能打开看当天成果。

## 目录结构

```
ecommerce-watch/
├── .github/workflows/daily.yml   # 云端定时任务（每天 0:05 自动跑）
├── scripts/                      # 所有自动化脚本
│   ├── common.py                 # 通用工具（路径/日志/去重/数据库）
│   ├── config.json               # 你的配置（关键词/EXCLUDE店铺/推送等）
│   ├── collect_taobao.py         # 淘宝采集
│   ├── collect_xianyu.py         # 闲鱼采集
│   ├── fetch_detail.py           # 抓详情页SKU/价格/描述
│   ├── download_images.py        # 下载商品主图 + 读卖点
│   ├── build_outputs.py          # 生成数据文件 + PPT + 详情卡片图
│   ├── report_failures.py        # 生成失败说明
│   ├── verify_files.py           # 校验文件是否齐全
│   ├── ingest.py                 # 通用自动入库接口（去重/归档/记录）
│   └── run_all.py                # 一键串联全流程
├── workbench/                    # 个人工作台网页
│   └── index.html
└── archive/                      # 云端归档目录（每天自动生成 2026-09-30/）
```

## 数据来源与真实性声明

- 采集使用真实网络请求抓取（淘宝/闲鱼公开页面与接口）。
- 淘宝和闲鱼有登录墙、验证码、风控。**抓不到的字段一律标记「待核」并提供原因，绝不编造价格、销量等数据。**
- 失败的商品不影响其他商品继续采集。
